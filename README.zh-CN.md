# LINE Sticker Downloader

[English](README.md) · [简体中文](README.zh-CN.md)

轻量级 Chromium 扩展，用于从 LINE Store 产品页面选择性下载贴图和表情包资源。

选择所需内容，直接下载，并可选将 APNG 动态文件转换为 GIF——所有操作均通过注入 LINE Store 页面的紧凑浮动界面完成。

本项目为独立的非商业个人研究项目，旨在探索浏览器扩展开发、网络资源处理以及客户端图像处理技术。

## 功能特性

### 选择性下载

精确选择要下载的贴图或表情包。

- 单独选择单个项目
- 全选 / 取消全选
- 反选
- Shift 点击选择范围
- `Ctrl+A` / `⌘A` 全选或取消全选
- 仅下载已选中的项目
- 显示当前选中数量

### 静态与动态内容

可处理静态和动态两种资源类型。

- 将静态贴图下载为 PNG
- 以原始 APNG 格式下载动态贴图
- 将动态 APNG 转换为 GIF
- 提供以下模式选择：
  - 仅静态
  - 仅动态
  - 静态 + 动态

### APNG → GIF 转换

动态贴图可直接在浏览器中从 APNG 转换为 GIF。

转换过程：

- 在本地运行，无需远程处理服务器
- 保留动画帧时序
- 尽 GIF 格式所能保留透明背景
- 采用自定义哨兵色方案，减少深色或黑色像素被意外透明化的情况

GIF 转换为可选功能，禁用时将直接下载原始 APNG 资源。

### 浮动界面

扩展使用紧凑浮动气泡，而非固定侧边栏。

- 展开 / 收起控制面板
- 拖动气泡重新定位
- 自动吸附至最近的屏幕边缘
- 记忆位置
- 打开面板时自动启用下载模式
- 关闭面板时自动禁用下载模式
- 按 `ESC` 关闭面板

界面设计保证在不使用下载器时，LINE Store 页面基本不受遮挡。

### 多语言界面

目前支持以下语言：

- 简体中文
- 繁體中文
- 日本語
- English
- 한국어

所选语言将本地保存于浏览器中。

## 为什么做这个项目？

现有的许多贴图下载工具会将整套资源连同预览图和元数据文件一并打包提供。

本项目围绕更简洁的工作流构建：

**选择所需内容 → 直接下载 → 可选转换动态内容为 GIF。**

本项目既是个人实用工具，也是实践以下技术的练习项目：

- Chromium 扩展开发
- Manifest V3
- DOM 操作
- `MutationObserver`
- 网络资源处理
- 客户端图像处理
- APNG 解码
- GIF 编码
- 异步批处理

本项目不提供贴图存档，也不包含已下载的贴图内容。

## 工作原理

扩展检测到受支持的 LINE Store 贴图和表情包产品页面后，会向页面注入自有的浮动界面。

启用下载模式后，可选控件将添加至可用的贴图或表情包项目上。

扩展使用 LINE Store 页面上已有的资源信息，包括静态和动态资源的 URL。

用户启动下载时：

1. 收集已选中的项目。
2. 若信息可用，使用产品名称和作者名称组织下载文件。
3. 静态资源以 PNG 格式下载。
4. 动态资源可选择下载为 APNG，或在本地转换为 GIF。
5. 各项目按顺序处理，每项之间有短暂延迟。

GIF 转换时，APNG 由浏览器获取并在本地处理，生成的 GIF 随后传递至扩展的后台 Service Worker 进行下载。

## APNG → GIF 转换

APNG 通常提供比 GIF 更好的透明度和色彩处理能力，但部分应用程序和平台不能正确支持动态 PNG。

因此，本项目提供可选的 APNG → GIF 转换路径。

转换管线使用：

- `UPNG.js` — APNG 解码
- `GIFEncoder.js` — GIF 编码
- `NeuQuant` — 颜色量化
- `LZWEncoder` — GIF LZW 压缩
- `pako` — zlib / DEFLATE 支持

所有图像处理均在浏览器本地完成。

### GIF 透明度编码

GIF 仅支持单一透明调色板索引。

若以黑色等常用颜色作为透明色，简单实现可能导致深色像素被意外透明化。

本项目改用**哨兵色方案**：

1. 检查不透明图像颜色。
2. 尽可能选取不与图像冲突的候选颜色。
3. 以候选颜色临时表示透明像素。
4. 将哨兵色保留为 GIF 透明调色板条目。
5. 必要时重新映射调色板索引，避免已有深色像素丢失。

该方案对含有黑色轮廓线、眼睛、阴影或其他深色细节的贴图尤为有效。

### 帧处理

转换管线：

1. 使用 `UPNG.decode()` 解码 APNG。
2. 使用 `UPNG.toRGBA8()` 提取 RGBA 动画帧。
3. 使用原始帧延迟时间。
4. 将原始 RGBA 图像数据传入 GIF 编码器。
5. 将动画编码为 GIF Blob。
6. 将生成的 Blob 发送至后台 Service Worker 进行下载。

## 文件命名

下载内容以检测到的产品名称和作者名称组织（若信息可用）。

目录结构大致如下：

```text
贴图包名_作者名/
├── 01_STICKER_ID.png
├── 02_STICKER_ID.png
└── ...
```

动态资源：

```text
贴图包名_作者名/
├── 01_STICKER_ID.gif
└── ...
```

启用 GIF 转换时如上所示。否则，原始动态资源以 `_ANIMATION.png` 后缀下载。

## 隐私

扩展无需专用的远程处理服务器。

APNG → GIF 转换在浏览器本地完成。

当前实现不包含任何分析或遥测服务。

扩展在受支持的 LINE Store 产品页面上运行，并请求 `manifest.json` 中指定的、用于下载文件及访问 LINE Store / LINE 贴图 CDN 资源所必需的权限。

安装前，建议用户审阅源代码及所请求的权限。

## 安装

本扩展目前以本地安装方式用于 Chromium 系浏览器，而非通过扩展商店分发。

### Chrome / Edge

1. 下载或克隆此仓库。

2. 在 Chrome 中打开 `chrome://extensions/`，或在其他 Chromium 系浏览器中打开扩展页面。

3. 启用**开发者模式**。

4. 点击**加载已解压的扩展程序**。

5. 选择项目目录。

6. 打开受支持的 LINE Store 贴图或表情包产品页面。

7. 下载器气泡应自动出现。

本扩展当前使用 Manifest V3。

## 已知限制

- GIF 仅支持 1 位透明度，半透明边缘效果可能与原始 APNG 有所差异。
- GIF 颜色量化可能引入轻微色偏，在渐变或色彩复杂的图像中尤为明显。
- 大型动态贴图的转换可能耗时较长。
- 动态转换要求对应的 APNG 资源可访问。
- 扩展依赖 LINE Store 页面的当前结构，若网站更新则可能需要相应修改。
- GIF 通常保留的色彩和透明度信息少于 APNG。
- 扩展当前仅针对 `manifest.json` 中定义的受支持 LINE Store 贴图和表情包产品页面格式。
